## Реквесты, связанные с сообщениями
* send_message: message - запрос на отправку сообщения message
* delete_message: id_message - запрос на удаление сообщения с id id_message. Возможно только при наличии прав администратора в чате
## Реквесты, связанные с чатами
* create_new_chat: chat_name - запрос на создание нового чата. При успехе, пользователь автоматически получит права администратора
* add_user_to_chat: other_user_login id_chat - запрос на добавление в чат пользователя с заданным логином. Возможно только при наличии прав администратора в чате
* remove_user_from_chat: other_user_login id_chat - запрос на удаления пользователя с заданным логином из чата. Возможно только при наличии прав администратора в чате
* get_chat_name: id_chat - получение название данного чата
