# **Базовые концепции проекта**

## **Основные объекты**

### Пользователь/User
Пользователь может:
1. **Посылать сообщения**
2. **Удалять сообщения** - только свои, если пользователь не обладает правами администратора, и любые, в противном случае.
3. **Загружать файлы на сервер**
4. **Удалять свои файлы с сервера**
5. **Создавать чат** - при создании чата пользователь автоматически получает права администратора.
6. **Добавлять людей в чат** - только при наличии прав администратора.
7. **Удалять людей из чата** - при наличии прав администратора любого пользователя, иначе только себя. Если пользователь был администратором, то после выхода из чата следующим администратором становится **случайный** участник.
8. **Удалять чат** - только при наличии прав администратора.
9. **Отказаться от прав администратора** - только при наличии прав администратора.
10. **Менять свой логин или пароль**
## Пользователь обладает следующими свойствами:
1. **id_user** - используется для идентификации пользователя сервером.
2. **user_name** - используется для регистрации и последующих авторизаций.
3. **password** - используется для регистрации и последующих авторизаций. Хранится сервером **только** в виде хеша.
4. **info** - дополнительная информация о пользователе.
### Чат/Chat
Чат - объект, с помощью которого сервер может определить, какие сообщения, каким пользователям нужно отправить.
Чат обладает следующими свойствами:
1. **id_chat** - используется для идентификации чата сервером.
2. **chat_name** - отображаемое название чата.
3. Информация о пользователях, состоящий в чате, который включает: \
3.1 id_user - id пользователя. \
3.2 permission - права, которыми обладает пользователь. \
3.3 last_online - время, когда пользователь в последний раз просматривал чат. 
### **Сообщение/Message**
Сообщение обладает следующими свойствами:
1. **id_message** - используется для идентификации сообщения сервером.
2. **id_from_user** - id пользователя, который его отправил.
3. **id_to_chat** - id чата, в который было отправлено сообщение.
4. **send_time** - время отправки сообщения, или время его удаления.
5. **is_delete** - не удалено ли сообщение, если удалено, следующие два поля пусты.
6. **text** - текст сообщения.
7. **id_attached_files** - id прикрепленных к сообщению файлов.
### **Файл/file**
Файлы могут быть произвольного типа. С помощью сообщений пользователи могут обмениваться ссылками на свои файлы на сервере, и загружать их оттуда. Размер файла не должен превышать 10 Мб.
Файл обладает следующими свойствами:
1. **id_file** - используется для идентификации сообщения сервером.
2. **id_owner** - id пользователя, которому принадлежит файл.
3. **file_name** - название файла.
4. **file_path** - путь, по которому хранится файл на сервере.
5. **file_size** - размер файла. 0 - если файл удален.
